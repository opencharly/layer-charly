# 2026.321.0749 — fix(charly)!: move the tailscale apt repo to the resolute suite

## Summary

Adds an **`ubuntu-26.04:` section** to the `charly` candy's `distro:` map so a 26.04 image gets the
**resolute** tailscale apt suite, and leaves the generic section on `noble` for the 24.04 consumers that still
resolve through it.

Head `02cdde4`, **1 file, 11 insertions(+)**, net against `main`: one new `distro:` section, nothing changed.

```yaml
ubuntu:            # unchanged — noble, correct for the 24.04 consumers below
    repo: tailscale … noble.noarmor.gpg / suite: noble
ubuntu-26.04:      # NEW
    repo: tailscale … resolute.noarmor.gpg / suite: resolute
```

### Why this shape — my first version was wrong

My first version rewrote the tailscale repo in the **generic `ubuntu:`** section from `noble` to `resolute`, and
justified it with *"none does in the org today"*. That was an assertion, the review refused it, and the grep
says otherwise:

```
$ grep -rn 'ubuntu:24.04\|ubuntu-24.04' --include=charly.yml . \
    | grep -vE '_candy|\.build|\.check|CHANGELOG|/\.worktrees/'
./distro-ubuntu/box/ubuntu/charly.yml:3:              base: ubuntu:24.04
./distro-ubuntu/box/ubuntu/charly.yml:15:             - ubuntu:24.04
./distro-ubuntu/box/ubuntu-debootstrap/charly.yml:9:     - ubuntu:24.04
./distro-ubuntu/box/clawsweeper-review/charly.yml:5:   base: ubuntu:24.04
./plugin-mise/charly.yml:73:        base: ubuntu:24.04
./plugin-mise/charly.yml:154:        distro: [ubuntu:24.04, ubuntu]
```

Those boxes resolve `ubuntu:` too, so that edit would have served them a 26.04 repository. The versioned key
must be **added**, not repurposed — the resolver matches most-specific-first, and packages union with
`ubuntu:`, so the new section carries only the repo override.

### Why the suite matters at all

This declaration is what writes `/etc/apt/sources.list.d/tailscale.list` inside a guest. With `noble`, a 26.04
bed's check failed on exactly that:

```
FAIL check command=grep -h 'pkgs[.]tailscale[.]com/stable/ubuntu resolute' \
       /etc/apt/sources.list.d/tailscale.list   [tailscale-repo-suite-ubuntu-resolute]
```

Measured: a VM bed built from a binary that already carried the 26.04 vocabulary still installed the guest
from the noble suite — its deploy log showed `pkgs.tailscale.com/stable/ubuntu noble` three times. The
vocabulary could not move it; this candy's own declaration is the source.
