# 2026.330.1658 — fix(arch): pin charly 2026.328.1515, the version the charly-arch repo serves

## Summary

Pin the Arch `charly` package to **`2026.328.1515`**, the version the `charly-arch` repo actually
serves. The candy pinned `charly=2026.326.1922`, which the repo no longer carries, so `pacman -Syu`

on `distro-arch`'s `arch-coder`.
